# データを更新する

ルートで `pnpm data:refresh` を実行する。
元サイトのCSV一覧から2024年以降を取得。サイズ・タイムアウト・取得先を制限する。
生CSVはSHA-256名で追記し、同名の内容が異なれば停止する。取得・解析失敗で掲載済みJSONを変更しない。

- 同一原本は同一取得記録を保ち、JSONを書き換えない。
- 新しい時点は、数値検査後にローカルの公開JSONへ追加する。Web公開は別途ビルド・デプロイする。
- 過去の値が変わった場合は `artifacts/population-candidate.json` と差分を出して停止する。
- 形式変更・参照切れ・欠測は `artifacts/ingestion-failure.json` に記録する。

過去値の訂正を採用する際は、原本と変更理由を確認し、対象値と出典のハッシュをレビュー記録に残す。
確認後に候補JSONを `data/published/population.json` へ移し、`pnpm verify` を実行してPRで履歴を残す。
以前の `data/raw/` と `data/manifests/` は削除しない。

週次GitHub Actionsは検査のみを実行する。更新候補や取得失敗はジョブ失敗で可視化し、成果物を30日保存する。
Actions失敗通知はリポジトリ管理者がGitHubで受け取る。独自メール・Slack送信は未設定。
新データが出ても自動公開しない。管理者が差分を確認して取り込み、WebとMCPを同じcommitからデプロイする。

現在の32か月・9指標は人口統計のみ。予算・政策・年齢別人口を収録済みと報告しない。
文章レビューの型・ゲートは `packages/core/review.ts` にあるが、AI生成ワークフローは未導入。
AI検証の主張ID・引用ID・本文ハッシュを照合する契約テストを提供している。現在の数値公開は原典の直接検査を使う。
