# 基本テーマと期間限定テーマ

2026-09-05実装。

## 配色

基本は `yokohama`。海をイメージした青 `#0067A6`、白、深い紺。
[横浜市の地域まちづくり20周年の説明](https://www.city.yokohama.lg.jp/kurashi/machizukuri-kankyo/toshiseibi/suishin/chimachi20th.html)でも横浜のテーマカラーはブルーとされる。
ここで採用したHEX値は本プロダクト独自のパレットで、市の公式指定色を転記したものではない。

期間限定は `green-expo`。葉の緑 `#286544` と淡い若葉色を使用する独自パレット。
公式ロゴや公式ブランドカラーを使ったものではない。
カテゴリの色の意味は維持する。夜間の解釈ラベルは同じ橙系で明度を上げる。
見出し、ボタン、背景、罫線、グラフ、港のイラスト、favicon、ブラウザのtheme-colorをそろえて切り替える。

## 設定

`packages/core/theme.ts` の `themeConfig` を編集する。

- `defaultTheme`: 通常の配色。
- `override`: `null` なら自動判定。テーマIDを指定すると全期間固定。
- `nightEnabled`: 日没から翌日の出まで夜景を使う。現在は `true`。
- `seasons`: `theme`、`startsAt`、`endsAt`、`enabled`。期間が重なる場合は上に書いた設定を優先。

GREEN×EXPO 2027の[公式開催期間](https://expo2027yokohama.or.jp/about/overview/)を例に、
2027-03-19 00:00 JST以上、2027-09-27 00:00 JST未満の設定例を残している。
ユーザーの保留方針により現在は `enabled: false`。公式素材も未使用。
再開時に有効化すると期間中は緑を優先し、終了後は通常の昼夜判定に戻る。

期間の判定は閲覧端末で行い、切替のための再ビルド・Cron・DB・有料サービスは不要。
初回描画前、ページ再表示、タブ復帰、開きっぱなしの場合は1分ごとに再判定する。
判定の時刻は端末時計に依存する。JavaScript無効時は基本テーマで表示する。
設定自体を変更した場合は通常どおりビルド・デプロイする。

## プレビュー

- 青: `/?theme=yokohama`
- 夜景: `/?theme=yokohama-night`
- 緑: `/?theme=green-expo`

URLを開いたページだけに適用し、Cookieやローカルストレージへ保存しない。
不明な値は通常の期間判定に戻す。プレビューは全体の公開設定を変更しない。

## 検証

開始直前・開始・終了直前・終了の日本時間の境界、手動固定を単体テスト。
ブラウザ時刻を進め、静的HTMLのまま日の出・日没で切り替わることを確認。
PC/スマホで各パレットのWCAG A/AA自動検査を行う。

## 日没後の港の夜景

横浜の代表地点（北緯35.45度・東経139.65度、標高0m）で日の出・日没を計算する。
国立天文台の横浜の暦と同じ座標を使用。端末のタイムゾーンにかかわらず日本の日付で判定する。
位置情報・外部API・追加パッケージ・閲覧時のサーバー処理は不要。

- 日没時刻以上: 濃紺の背景、金色の港の照明、水面の反射、装飾の月・星。
- 翌日の日の出時刻以上: 通常の横浜ブルー。
- 優先順: URLプレビュー → 手動固定 → 有効な期間テーマ → 昼夜判定 → 基本色。
- 夜景も表・検索フォーム・グラフを含めて配色をそろえる。印刷時は白背景。
- 月と星は装飾であり、実際の月相・星の位置・天候を表示するものではない。

計算は[NOAAの太陽位置近似式](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF)による。
地形・雲・標高は考慮しない。公式な時刻提供ではなく、数分程度の差を許容する演出用の近似。
表示中は1分間隔で再判定するため、計算時刻から最大約1分の追加遅延がある。
バックグラウンドではタイマーを抑制される場合があり、タブ復帰時に再判定する。
JavaScript無効時は昼の青。端末時計が誤っている場合は切替時刻もずれる。

独立した照合値: 国立天文台の[2026年6月](https://eco.mtk.nao.ac.jp/koyomi/dni/2026/s1506.html)、
[9月](https://eco.mtk.nao.ac.jp/koyomi/dni/2026/s1509.html)、
[12月](https://eco.mtk.nao.ac.jp/koyomi/dni/2026/s1512.html)。
選んだ5日の日の出・日没との誤差3分未満をテストする。全日程の精度保証ではない。
日本時間の日付境界・うるう日・日の出/日没の境界、夜間のアクセシビリティも検証する。
