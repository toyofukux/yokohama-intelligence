# ドメイン候補

2026-09-05時点のネーミング案を記録しています。現在は `open.yokohama` を採用し、公開しています。候補一覧は当時の比較資料として残しています。

| 候補 | 狙い |
|---|---|
| shiru.yokohama | 当時の「横浜を知る」と一致。市民への伝わりやすさを重視した第一候補 |
| hama.today | 短く、毎日開くまちのメディアという印象 |
| our.yokohama | 「私たちの横浜」。公共性と参加のしやすさ |
| hama.city | 短く、まち全体の基盤へ広げやすい |
| hama.guide | 暮らしの案内として親しみやすい |
| yokohama.fyi | 横浜について知っておきたいこと、という軽さ |
| hama-lens.jp | 地域を詳しく見る道具という意味 |
| hamamiru.jp | 「ハマを見る」。日本語で口にしやすい |
| hamashiru.jp | 「ハマを知る」。覚えやすく用途が伝わる |
| open.yokohama | 情報とコードを開く姿勢を示す |

当時の推奨: サービス名を育てるなら `shiru.yokohama`。短いブランドを作るなら `hama.today`。
選定後は初年度価格だけでなく更新料を確認し、取得後にCloudflareの独自ドメイン・canonical・sitemapをそろえてください。
